# Gerador de portfólio

/create-portfolio organiza dados de apresentação e projetos em um template de portfólio. O formulário controla seleção de modelo, dados e preview; a geração converte o resultado em HTML e link para o renderizador. Consulte o formulário e os builders vinculados para os campos suportados.

O compartilhamento transporta uma cópia do conteúdo. Não cria repositório GitHub, não provisiona domínio e não sincroniza projetos automaticamente. Recursos remotos continuam hospedados nos seus endereços originais.

Valide se os links dos projetos abrem, se as imagens existem e se a página fica legível em telas pequenas. Alterações exigem gerar e distribuir um novo link. Textos e URLs que viajam no payload são públicos para os destinatários.
